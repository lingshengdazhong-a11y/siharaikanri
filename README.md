# 月々の支払い管理アプリ

スマートフォン・PCのブラウザで使える、個人用の支払い管理アプリです。外部ライブラリやサーバー、ログインは不要です。

## 主な機能
- 月ごとに支払い一覧を分けて管理
- 合計額、支払い済み額、未払い残額、完了率を自動集計
- 支払い項目の追加・編集・削除
- 支払い済み／未払いの切り替えと絞り込み
- カテゴリー、支払日、メモ、毎月／当月のみの項目設定
- localStorage による端末内保存
- JSON形式のバックアップ・復元
- PWA対応（HTTPSまたはlocalhostで配信した場合、対応ブラウザでホーム画面追加・キャッシュ利用可能）

## 使い方
### すぐに使う
`index.html` をブラウザで開きます。支払いの登録・月別管理・端末内保存・バックアップ／復元を利用できます。

### スマホのホーム画面に追加して使う（推奨）
PWAのインストールには、通常HTTPSでの公開またはlocalhostが必要です。`index.html`、`style.css`、`app.js`、`manifest.json`、`sw.js`、`icon.svg` を同じディレクトリに置き、HTTPS対応の静的ホスティングにアップロードします。iPhoneではSafariの共有メニューから「ホーム画面に追加」を選びます。Androidでは対応ブラウザのメニューからインストール／ホーム画面に追加を選びます。

## データ保存について
データは利用中のブラウザの localStorage に保存され、同じブラウザ・同じ端末で再度開くと復元されます。ブラウザのサイトデータ削除、プライベートブラウズ、端末故障、別端末への移行などで失われる可能性があるため、定期的に「バックアップ」からJSONファイルを保存してください。クラウド同期・銀行連携はありません。

## 月ごとの扱い
各月は独立した一覧です。項目の「毎月」は繰り返し設定の記録として保存されますが、現時点では翌月への自動複製は行いません。翌月にも登録する場合は、その月で項目を追加してください。
